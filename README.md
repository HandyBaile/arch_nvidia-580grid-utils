# ArchLinux `nvidia-580grid-utils`
`nvidia-580grid-utils` is a modification of the [`nvidia-580xx-utils`](https://aur.archlinux.org/packages/nvidia-580xx-utils) AUR package, meant to be used with NVIDIA's 19.0 vGPU Grid Drivers and this [Guide](https://gitlab.com/polloloco/vgpu-proxmox) by PolloLoco.

Requires Linux 6.14 or older.
